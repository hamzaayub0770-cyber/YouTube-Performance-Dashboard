# 📊 YouTube Performance Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **YouTube Performance Dashboard** developed in **Microsoft Power BI**. It transforms raw YouTube data into meaningful business insights using data cleaning, data modeling, DAX measures, and interactive visualizations.

The dashboard helps analyze video performance, channel performance, audience engagement, and viewing trends through a three-page interactive report.

---
## 📈 Business Problem

YouTube generates a large amount of performance data, making it difficult to quickly identify top-performing videos and channels. This dashboard provides an interactive solution to monitor key metrics, compare channel performance, analyze audience engagement, and support data-driven decision-making.


## 🎯 Objectives

- Analyze YouTube video performance.
- Compare channel performance.
- Identify top-performing videos and channels.
- Monitor views over time.
- Measure audience engagement.
- Build an interactive business intelligence dashboard.
